# Contas

Saldo inicial é o ponto de partida a partir do qual as transações em `transacoes.md` contam. Contas de dívida (cartões, empréstimos, a pagar) começam **negativas**.

Saldo atual de cada conta é calculado sob demanda pelo Claude:
`Saldo Inicial + Receitas − Despesas + Transferências recebidas − Transferências enviadas`.
