# Referências

## Filosofia do produto

Dado primeiro, decoração depois. A interface existe para tornar os números legíveis e acionáveis — não para impressionar.

Clareza > estética elaborada. Se a tabela responde a pergunta, não precisa de gráfico.

## Referências de produto

**YNAB (You Need A Budget)**
Filosofia de orçamento baseada em dar destino para cada real antes de gastar. Influencia a forma de pensar sobre categorias e limites.

**Copilot Money**
Referência de UX limpa para apps de finanças pessoais. Boa organização de transações e visão de padrões.

**Notion Finance Templates**
Referência de como uma planilha bem estruturada pode resolver muito sem precisar de código. Útil para pensar na Fase 1.

## Restrições técnicas

- A solução precisa ser implementável e mantível no dia a dia
- Sem dependências externas desnecessárias (APIs bancárias, serviços pagos)
- Deve ser possível exportar os dados — sem lock-in

## Notas

O ponto de partida mais simples que resolve o problema real é a escolha certa. Escalar depois, se precisar.
